Tratamento de dados

Como as informações são utilizadas

1. Dados coletados

O formulário de contato pode coletar nome, e-mail, telefone, tipo sanguíneo e mensagem, quando informados pelo usuário.

2. Finalidade

Esses dados são utilizados para registrar contatos enviados à plataforma e apoiar o funcionamento do projeto.

3. Compartilhamento

O HemaVita Campina não comercializa dados pessoais. As informações são usadas apenas no contexto do projeto, salvo obrigação legal.

4. Segurança

São adotadas medidas razoáveis para proteção das informações, embora nenhum ambiente digital seja totalmente livre de riscos.

5. Atualizações

Esta política poderá ser alterada a qualquer momento mediante publicação de nova versão nesta página.
