# HemaVita Campina

Projeto acadêmico com foco em facilitar o acesso à informação sobre doação de sangue.

## Tecnologias
- HTML
- CSS
- JavaScript
- Node.js
- Express

## Deploy
Front: Netlify  
Backend: Render

## Funcionalidades
- Informações sobre doação
- Campanhas dinâmicas
- Requisitos via API
- Formulário de contato
